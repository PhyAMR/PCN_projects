# Network reconstruction from EvoSim eco-evolutionary trajectories 

Score: 1.2

*EvoSim is a mechanism-oriented artificial-life simulator for eco-evolutionary dynamics in chemically structured environments. Modern EvoSim produces rich simulation outputs, including organism trajectories, type abundances, lineages, genotype-to-functional-profile maps, reaction networks, metabolic fluxes, catalysis events, RAF-like autocatalytic sets, and ex-post theoretical observables. These outputs can be used to reconstruct temporal networks generated by artificial evolutionary dynamics.*

*The objective of this project is to use EvoSim outputs as synthetic data for network reconstruction and analysis. Students should reconstruct multiple temporal network representations from the same simulations and study how their structure changes during adaptation, diversification, metabolic organization, or collapse.*

--

Students should either run new EvoSim simulations or use existing EvoSim output files provided by the Professor. They should use the modern metabolic engine when possible, keeping the legacy engine only as a baseline comparison.

Students should reconstruct at least two types of networks. Possible choices include:

- lineage networks, where nodes are organisms or lineages and edges represent parent-offspring relations;
- genotype or functional-profile similarity networks, where nodes are genotypes, types, or functional profiles and edges connect similar entities;
- protein co-occurrence networks, where nodes are protein sequences and edges connect proteins appearing in the same organism;
- reaction or catalysis networks, where nodes are molecules, reactions, proteins, or catalysts and edges represent biochemical or catalytic relations;
- spatial proximity networks, where nodes are organisms and edges connect organisms occupying nearby grid cells at the same epoch.

Expected output:

- cleaned EvoSim trajectory data, either generated by the students or provided by the Professor;
- at least two reconstructed temporal network types;
- node and edge files for each reconstructed network;
- scripts for network reconstruction and analysis;
- visualizations of selected temporal network snapshots;
- a short report describing the network definitions, preprocessing rules, and main results.

For each network snapshot, students should provide:

- node file: `nodeID nodeLabel type epoch additional_attributes`;
- edge file: `nodeID_from nodeID_to weight epoch`;
- documentation of how nodes and edges were defined;
- explanation of whether the network is weighted, unweighted, directed, or undirected.

The analysis should include:

1. selection or generation of EvoSim simulation outputs;
2. reconstruction of at least two network representations from the same evolutionary trajectories;
3. computation of temporal network statistics, including number of nodes, number of edges, connected components, degree distribution, clustering, modularity, and turnover;
4. comparison between network evolution and population-level quantities such as population size, energy, biomass, diversity, extinction risk, and RAF persistence;
5. analysis of whether network structure changes before collapse, diversification, qESS-like persistence, or metabolic reorganization;
6. comparison between different simulation scenarios, such as generated RAF, open chemistry, metabolic mode, and legacy baseline;
7. discussion of which network representation is most informative about the underlying eco-evolutionary dynamics.

Optional extensions (up to +0.5):

- compare networks across ablation experiments with different mechanism switches;
- analyze multiplex relations among genotype, lineage, metabolism, and spatial proximity networks;
- test whether early network descriptors predict survival or extinction;
- compare structural RAF-like networks with dynamically active metabolic flux networks;
- build lineage-level networks of inherited functional profiles.

This project can also be expanded into an internship and thesis project, focusing on a systematic framework for reconstructing, comparing, and modeling temporal networks generated by artificial-life evolutionary dynamics.
